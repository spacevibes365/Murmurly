# Text delivery

Feature layer. How dictated text reaches another app: the clipboard and a synthetic ⌘V (`TextInjector`), `deliver`,
and the last dictation again (⌃⌘V / ⌃⌘C) in `DictationCoordinator`.

- **This Mac only.** `inject` writes the text and restores the old clipboard with `.currentHostOnly`: an ordinary
  write would make Universal Clipboard announce the old contents as the newest copy. Only an explicit copy (`place`)
  is an ordinary write.
- **Mark, then read `changeCount`.** The pasted text carries `org.nspasteboard.TransientType` and `.AutoGeneratedType`;
  the marks advance `changeCount`, and the restore must tell someone else's copy from our own write.
- **Restore only an unchanged clipboard**, and never carry `com.apple.is-remote-clipboard` into the restored copy: a
  local write would look like another device's.
- **A password field gets nothing.** `focusedFieldIsSecure()` is asked before any clipboard write or activation and
  again once the target is in front; `true` means no paste, no clipboard, no fallback. `nil` pastes as before.
- **Only the `AXSecureTextField` subrole counts.** Never ask `IsSecureEventInputEnabled`: Terminal's Secure Keyboard
  Entry or a password manager turn it on for every field. Keep the 0.25 s messaging timeout: the query runs on the
  main actor, and a hung app must not hold the paste.
- **Murmurly is never a target.** `preferredInjectionTarget` and both paste paths skip the app's own process, so
  nothing is pasted into the notepad or the main window.
- **All four ⌘V events or none**, with explicit flags: a lone ⌘-down would leave the modifier stuck.
- **`dictation.autoPaste` off** means no paste and no clipboard write; it comes from `recordingSnapshot`; ⌃⌘V and ⌃⌘C
  ignore it.
- **⌃⌘V reads the last dictation fresh** (`lookUpLast`), never from `recentDictations`; it pastes only once ⌃⌥⇧⌘ are
  released, into the app in front at key-down, and a history that cannot be read refuses rather than guess.
- **A paste under way is never cancelled.** `deliveringPaste` runs it in a task of its own and sets
  `pasteDelivering` before its first suspension; quit waits for it, so the clipboard is always restored.
- **`deliver` and `runPasteLast` are the same sequence written twice.** A change to one belongs in the other.

How it works: `reference/dictation.md`.
